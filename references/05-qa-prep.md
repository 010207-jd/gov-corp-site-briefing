# 05 · 问答预案

现场讲解被打断提问是常态，不是意外。预案不是背答案，是背**结构**。

## 一、问题六类与应答骨架

| 类型 | 典型问法 | 应答结构 |
|---|---|---|
| 数据核实 | 这个数怎么来的？和去年比呢？ | 口径 + 数值 + 出处 |
| 做法细节 | 具体怎么操作的？谁来干？ | 流程三步 + 责任主体 |
| 成效质疑 | 真的有用吗？企业感受到没有？ | 承认难度 + 一个具体案例 + 一个客观指标 |
| 投入产出 | 花了多少钱？值不值？ | 投资额 + 单位成本 + 回收周期或替代成本 |
| 短板问题 | 现在最大的困难是什么？ | 一个真短板 + 已采取措施 + 时间表 |
| 未来规划 | 下一步怎么打算？ | 一句话方向 + 一个可验证节点（不承诺结果） |

## 二、三段式应答（万能结构）

**第一句给结论**（10 秒内）→ **第二句给证据**（一个数或一个例子）→ **第三句给落点**（引到下一个点位或表示随后细说）。

> 问：这个平台到底省了多少钱？
> 答：直接省的是重复建设这一块。全市原本 7 个区各自建平台，现在统一一套，一次性少投 4600 万。具体账目我们整理了一份材料，会后交给各位。

## 三、高频问题库（按场景，各备 3–5 条）

**政务调研**

1. 这项工作在全市/全省处于什么位置？→ 给排名或区间，不给"第一"。
2. 基层负担有没有增加？→ 承认前期有，讲压减措施与具体数字。
3. 可持续吗？钱从哪来？→ 财政 + 机制，说清来源结构。
4. 别的地区能复制吗？→ 讲可复制部分与不可复制部分（诚实反而可信）。

**企业 / 客户**

5. 交付周期多久？延期怎么办？→ 标准周期 + 违约条款。
6. 和XX家比优势在哪？→ 不比他人，只讲自身三项硬指标。
7. 售后响应多快？→ 具体时限 + 备件库位置。

**验收评审**

8. 这项指标为什么没达标？→ 差距数值 + 原因 + 整改节点。
9. 数据可追溯吗？→ 指向具体附件页码。
10. 和申报材料不一致？→ 说明变更依据与批复。

**指挥中心 / 数字政府**

11. 数据从哪来、准不准？→ 来源系统 + 校验机制 + 更新频率。
12. 有没有"两张皮"（线上线下一套、实际另一套）？→ 讲考核挂钩机制。
13. 断网了怎么办？→ 降级方案，一句话说清。

## 四、答不上来的四种说法（不编、不慌）

1. "这个数我需要核实准确口径，十分钟内给您准确答复。"
2. "这块是X同志具体负责，我请他补充。"
3. "目前掌握的是阶段性数据，正式数据以月报为准，会后一并报送。"
4. "这个问题提得很关键，我们回去专门研究，形成意见后报告。"

**绝不说**："应该是……吧""大概""我猜""肯定没问题"。

## 五、问答纪律

- 不抢话、不辩解、不反问对方。
- 一个问题只答一次，答完停住，不补充。
- 涉及其他单位的问题，只讲配合情况，不评价。
- 涉及未公开事项："这块内容目前还在走程序，完善后专题汇报。"
- 领导之间意见不一致时，不站队，回到事实。
