# 04 · 时长与现场交付

## 一、语速与字数换算

| 场景 | 语速（字/分钟） |
|---|---|
| 室内讲解，听众 10 人内 | 200–220 |
| 大屏/展厅，边走边讲 | 190–210 |
| 车间、户外、嘈杂环境 | 170–190 |
| 有翻译或同步记录 | 150–170 |

**换算公式**：`单节字数 = 单节时长（分钟）× 语速`。
含停顿、指引、等待反应的损耗，**一律按 200 字/分钟**估算，宁可估紧。

**总时长倒推**：

```text
有效讲解时间 = 总时长 − 迎宾寒暄 − 合影 − 座谈 − 领导即兴讲话 − 步行转场
总字数 = 有效讲解时间 × 200
```

示例：40 分钟参观，扣除迎宾 3 分、转场 5 分、合影 2 分、领导即兴 5 分 → 有效 25 分钟 → 约 5000 字，分 5 个点位，每点 800–1200 字。

## 二、时间配比

| 环节 | 占比 | 约束 |
|---|---|---|
| 开场 | 5%–8% | 不超 90 秒，30 秒内必须出现定性句 |
| 主体 | 82%–88% | 按点位权重分配 |
| 收尾 | 8%–10% | 不超 60 秒 |

**点位权重**：

- 核心点位（本次来访最想看的）：占主体 30%–40%
- 支撑点位：各占 15%–20%
- 过场点位（走廊、门口、展板）：60–90 秒，只讲一句定位 + 一个数字

**全部点位等长 = 没有重点 = 没有讲解。**

## 三、节奏设计

- 每 **150–200 字**安排一个"抬头点"：手指屏幕、看向实物、请对方往前走一步。纯听觉输入超过 40 秒，注意力必然下滑。
- 每 **40–60 秒**留一个可插入的停顿（句号处停半拍），给听众提问与反应的空间。
- 每节结尾一句过渡句，把动线交出去："接下来我们到隔壁看具体处置流程。"
- 避免连续三段都是"数据 + 数据 + 数据"，中间插一个案例或一句人话。

## 四、演练方法（交付时一并给用户）

1. **掐表法**：逐节计时朗读，与实际时长偏差超过 15% 的节必须增删。
2. **抽段法**：随机抽三节让非专业同事念，卡壳处即为要改的句子。
3. **录音回听**：录一遍自己听，凡是自己都想快进的地方，就是听众会走神的地方。
4. **提词卡降级演练**：只看提词卡关键词复述一遍，检验是否真的记住了逻辑。

## 五、突发应对（写进稿子的附页）

| 突发 | 处置 |
|---|---|
| 时间被压缩 30% | 预设"精简版"：砍掉支撑点位，保留开场定性 + 1 个核心点位 + 收尾。稿子里用 `【可删】` 标出。 |
| 领导中途提问打断 | 三步：先答结论一句 → 给一个数据 → "这点我随后详细汇报"。不纠缠。 |
| 时间被拉长 | 预设"扩展包"：每点位备 1 个故事、1 组对比数据，用 `【可展开】` 标出。 |
| 设备故障（大屏黑屏/视频不播） | 立刻转口述："屏幕暂时不通，我用一句话说清这块屏的核心。" 备一份录屏或打印图。 |
| 临时增加点位 | 用"通用点位话术"：定位 + 一句成效 + 一句衔接，不硬套原稿。 |
| 听众走神或接电话 | 主动停顿，改用提问式："各位可能会问，这个数是怎么来的？" |
| 忘词 | 只记每节第一个词和最后一个词，中间自由组织。提词卡只放关键词，不放整句。 |
| 天气或噪音 | 每段压到 40 秒内，靠近听众一侧说话，重要数字重复一遍。 |

## 六、稿件标记规范

主稿中用统一标记，便于现场取舍：

- `【可删】` — 时间紧时整段去掉
- `【可展开】` — 时间松时补充
- `【待补：XX】` — 事实缺口，必须在定稿前补齐
- `（动作）` — 圆括号内为体态与走位提示，不念出来
- `▮` — 停顿半拍
